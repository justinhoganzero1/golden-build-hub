# app-builder-autonomous rules
- App Builder photographs public website or app-store links (Firecrawl desktop + phone screenshots), reads public reviews/complaints and writes a gap audit, all wallet-billed per search/site with private addresses refused; the vision brief and audit (with legal-adaptation rules) guide every build stage and can be reused from a "scan" run via capped priorScan text, so members copy style and fix pain points but never brand names, logos, wording or photos. Contact details, proposals, emails and client demo links stay in the owner-only Pitch Machine (marketing).
- Builds carry a purpose (personal by default unless the request is clearly about selling, or the member picks "To sell" on the start card); personal builds skip pricing, paywalls, testimonials and the store-listing stage so own-use apps stay simple and private.
