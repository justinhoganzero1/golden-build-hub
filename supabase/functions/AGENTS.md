# supabase/functions rules
- Every text-AI edge function calls installNoRepeatRule() (_shared/noRepeat.ts), which appends the describe-once/no-repeated-jokes rule to chat-completions requests (image requests skipped) and the Responses helper; finished non-streamed prose also passes removeRepeatedSentences, so new AI features get the rule from one place. Code/classifier functions (oracle-coder, app-builder-autonomous, ai-moderate) are excluded because repeated lines are normal there.
- Oracle Racing parade clips are the owner's own recordings in the private racing-videos bucket (admin-only); the browser sends only ~6 small JPEG stills to racing-controller analyse_clip, and the observations are stored as AI interpretation that never changes finishing orders, because licensed broadcast footage can't be captured and whole videos are costly to send.
- Racing back-test trials use the market-baseline-v0 method (shortest pre-race price first) with empty validated_metrics, so a trial can never unlock live predictions; it is the bar a real model must beat.
- Oracle Racing math (features, conditional-logit model, CSV import) lives in pure _shared/racing*.ts tested by Vitest; the controller publishes finishing orders only from a model validated on time-ordered unseen races that beats the market, and past races never use current weather, to prevent leakage.
- Oracle Racing daily selections use _shared/racingSelection.ts (raise-only $3.00 floor also enforced by a DB check); selection decisions are append-only (DB trigger) and "no winners" is only reported after every broadcast race had a field, prices and tested probabilities, otherwise data unavailable.
- PuntersEdge (owner key via connector gateway, racing-controller/puntersedge.ts) supplies AU acceptances, best fresh bookmaker prices and results; every pull is throttled through racing_audit_log markers because the plan has a monthly credit cap, and prices stay labelled indicative.
