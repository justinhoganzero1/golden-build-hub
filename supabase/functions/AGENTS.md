# supabase/functions rules
- Every text-AI edge function calls installNoRepeatRule() (_shared/noRepeat.ts), which appends the describe-once/no-repeated-jokes rule to chat-completions requests (image requests skipped) and the Responses helper; finished non-streamed prose also passes removeRepeatedSentences, so new AI features get the rule from one place. Code/classifier functions (oracle-coder, app-builder-autonomous, ai-moderate) are excluded because repeated lines are normal there.
- Oracle Racing parade clips are the owner's own recordings in the private racing-videos bucket (admin-only); the browser sends only ~6 small JPEG stills to racing-controller analyse_clip, and the observations are stored as AI interpretation that never changes finishing orders, because licensed broadcast footage can't be captured and whole videos are costly to send.
- Racing back-test trials use the market-baseline-v0 method (shortest pre-race price first) with empty validated_metrics, so a trial can never unlock live predictions; it is the bar a real model must beat.
- Oracle Racing math (features, conditional-logit model, CSV import) lives in pure _shared/racing*.ts tested by Vitest; the controller publishes finishing orders only from a model validated on time-ordered unseen races that beats the market, and past races never use current weather, to prevent leakage.
- Oracle Racing daily selections use _shared/racingSelection.ts (raise-only $3.00 floor also enforced by a DB check); selection decisions are append-only (DB trigger) and "no winners" is only reported after every broadcast race had a field, prices and tested probabilities, otherwise data unavailable.
- PuntersEdge (owner key via connector gateway, racing-controller/puntersedge.ts) supplies AU acceptances, best fresh bookmaker prices and results; every pull is throttled through racing_audit_log markers because the plan has a monthly credit cap, and prices stay labelled indicative.
- host-lipsync (Replicate prunaai/p-video-avatar) holds funds before starting, keeps the clip private until billing_settle succeeds, charges the measured output seconds × the published USD rate × the AUD rate recorded at start (_shared/lipsyncPricing.ts) plus the standard margin, and cancels the hold on provider failure, so members pay only for clips they receive; interviews make one clip per person from per-speaker tracks (silence while the other talks) that follow the mixed voice while filming.
- Oracle News (news-controller + pure _shared/newsLogic.ts, Vitest-tested) reads only robots-permitted public RSS/article pages, recounts recent stories every scan by distinct publisher (detaching false groupings), and writes original scripts from verified stories; filming happens in the owner's browser newsroom studio, which uploads to private news-footage/broadcasts and attaches via attach_video, and only published broadcasts with a video reach members' archive, because no paid video API or footage bypass is allowed.
- Free-plan trials need no card: ensureTrialStart in _shared/freeTrial.ts records a free_trial_starts row (7 days from sign-up) on the first trial-card-setup status check-in or trial generation, and claim_free_trial then allows the trial pictures/video; older trial_card_checks rows still count (later end date wins). image-gen/gemini-video answer upgrade_required (reason duplicate/expired/used) and aiAccessEvents raises the plan paywall, never the wallet modal; failed trial generations give the item back.
- One free trial per person: when a trial starts, ensureTrialStart stores one-way hashes of the account's normalized email, device ID (localStorage+cookie+IndexedDB) and IP in service-only trial_identity_marks (kept after account deletion), refreshed by a daily check-in; a new Free account matching another trial account's mark gets a blocked trial row, while installs on any number of devices stay unblocked.
- Oracle chat access is decided server-side by memberChatAccess (_shared/freeTrial.ts): paid plans always, Free accounts during the 7-day trial window (from sign-up, or a later card-checked trial end) on their own Gemini key, otherwise plan_required, which OraclePage turns into the kind upgrade reply; the client never pre-blocks Free chat, so trial members always reach real AI.
- Owner member deletion goes through admin-delete-user only: requireOwner (protected admin role), never self or admin accounts, the exact email must match, live Stripe plans are cancelled before the account is removed (abort if cancelling fails), personal content (Gemini key, Library rows, memories, agents) is deleted while money records and trial marks are kept, and each deletion is written to auth_audit_log.
- Oracle Racing (/admin/racing, owner-only) runs through the racing-controller function: admin-only racing_* tables, service-only provider keys, engines record real runs in racing_engine_runs and report awaiting_configuration/waiting_for_data instead of inventing races, footage or predictions; locked predictions are immutable by trigger and finishing orders stay refused until a model is tested without future data.
- Oracle News produces story by story (news-controller/pipeline.ts + pure _shared/newsPipeline.ts, Vitest-tested): content → sectioned script → visuals (real clips of the story from recognised news broadcasters via YouTube search, stored as embed-only amber youtube_clip rows that play only in YouTube's player with credit and never enter filmed/downloaded video, because credit alone isn't permission to copy; plus NASA and Wikimedia Commons PD/CC0/CC BY/CC BY-SA files whose titles name every key search word) → ready_to_broadcast; only the top-ten stories by worldwide trendScore are produced and broadcast; the hourly tick advances 2 stories under a daily cap, failures retry 3× and stories older than 36 h expire, so nothing sits in the queue and AI cost stays bounded. Public /news shows only stories the owner published (public_at).
