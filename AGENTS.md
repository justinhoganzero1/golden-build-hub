# Project Rules
- Vite scans lazy feature sources before serving optimized React dependencies; keep one deduplicated React runtime so late tool discovery cannot mix renderer and hook module generations.
- OracleWorkspace keeps one canonical Oracle mounted while existing guarded tool routes render as returnable overlays; legacy direct routes remain available and Reimagined never shares this shell. Presenter clip selection is separate from speech and accepts only reviewed silent clips, with an honest portrait fallback.
- Library save recovery is account-scoped and validates the session owner before each retry; legacy unowned queues are retained but never drained into another account.
- Canonical Oracle stages typed completed artifacts before a user-selected reveal; generation and Library-save confirmation are separate, and device speech routes through the existing queue without invoking paid TTS. Live-video services require separate verified pricing and authorization.
- Movie Maker recent movies query only the signed-in account's saved video metadata; fetch and sign private media only on selection, and reuse Library records rather than duplicate storage.
- Reimagined whole-caseload preparation is deterministic and bounded to 1,000 claims; manager-confirmed tasks/drafts use stable IDs and versioned saves, while synthetic scale exercises never create accounts or replace saved claims, preserving human decisions and demo isolation.
- The independent Reimagined IT app owns separate Auth storage and protected manager/assigned-worker access; versioned manager drafts and worker case/messages are separate, worker RLS permits only assigned claims, and no demo account receives Oracle membership or paid AI/external actions. Detailed issue-response pop-ups separate sourced reports, demonstrated workflows and unproven outcomes.
- Library cards show readable titles outside large previews and lazily inspect visible apps and saved HTML documents in script-disabled, network-blocked frames; read only a bounded opening-page prefix from private storage so embedded videos do not load the entire library.
- Explicitly opened Library apps render in a full-screen isolated iframe with scripts enabled but no same-origin privilege or network requests; this makes saved HTML interactive without exposing account tokens, with a parent-owned Back to Library control.
- Preview URLs never bypass RequireAuth or plan access; missing membership means Free, preventing feature exposure.
- Plans resolve via member_plan (mirrored in src/lib/plans.ts); billing_authorize enforces service_required_plan so paid AI cannot bypass page locks; plan credits key per period so retries never double-credit.
- The independent WorkCover showcase uses fictional records and deterministic evidence checks, with human review before decisions; this avoids pretending to connect to official systems or deploying automated fraud verdicts.
- Resolve private storage URLs when opening Library items and before downloads; store permanent object references so saved files remain accessible after signed links expire.
- Bind paid fulfillment to server-owned prices, user and exact purchase; keep consumed founder sessions in a separate ledger so transfers cannot allow payment replay.
- Oracle paid requests require refreshed member tokens, never a public-key fallback; speech fetches are cancellable and startup must not synthesize billable warmups, to avoid stale authentication and unnecessary wallet contention.
- TTS reserves funds before synthesis and settles before releasing audio, with bounded billing/provider waits and no retry of uncertain payments; failures must never deliver unbilled provider audio.
- Oracle voice activation requires an explicit composer gesture and reuses its playback element; this respects microphone consent and mobile autoplay restrictions.
- Oracle microphone teardown runs only on page unmount or an explicit stop, never on render-dependent objects; otherwise listening silently shuts down during screen updates.
- Oracle voice playback streams decoded MP3 frames when supported and buffers only on unsupported browsers; early complete speech phrases reduce latency without replaying synthesis or bypassing billing.
- Route all app-wide Oracle launchers to the canonical /oracle chat instead of mounting a second chat engine, so microphone, model selection and tool execution have one owner.
- OraclePromptBox is the only main Oracle composer; keep UI separate from canonical chat dispatch and place advanced options behind its settings dialog so tools and saved work survive presentation changes.
- Rank available device voices through oracleDeviceVoice and preserve sentence punctuation; reviewed silent presenter loops remain independent of speech and never imply live lip-sync.
- Generated Oracle video replies use a versioned account-scoped preference and their own native audio; only consenting accounts default on, so new paid video generation is not silently enabled for members.
- Oracle video-reply mode suppresses separate speech dispatch and generation-failure TTS fallback, preventing mismatched voices over native clip audio; no unverified voice ID represents the ad recording.

- Whole-book rewrites must stage and validate every chapter before one final database replacement, because partial saves can corrupt a manuscript.
- Recovery must never automatically remount paid actions, replay uncertain side effects, or weaken authentication; preserve drafts and reconcile outcomes first.
- Large manuscript recovery uses account-scoped IndexedDB, while small Oracle drafts use account-scoped localStorage, to preserve artwork without exhausting browser quotas.
- Story recovery compares meaningful drafts after account loading, archives the offered copy separately and never blocks current device backups; only explicitly restored drafts require confirmation before account replacement.
- Pin the internal worker CORS SDK import to a version exporting that subpath, so edge runtime dependency snapshots cannot prevent all workers from booting.
- Daily monitoring performs SQL-only integrity checks and records deduplicated owner incidents; endpoint preflight checks are availability evidence, never proof of paid flows.
- Enforce the billing margin on database writes as well as pricing helpers; exempt only protected owner roles in compliance reports and preserve historical financial records.
- Long-running text generation uses the Lovable AI Gateway Responses API through shared server-only helpers, because credentials and prompts must never reach the browser.- Member AI agents, agent stats and chat histories live in the backend (user_agents, agent_stats, agent_chats) with localStorage only as a cache, so they follow the member across devices.
- Oracle live web answers go through oracle-research via a [[WEB: query]] reply marker and render cited sources; unsourced answers are labelled unverified so Oracle never presents invented facts.

- The gemini-video compatibility endpoint uses server-only Gateway video SDK jobs and private media storage; resume saved jobs, never replay unknown generation. Member generation fails closed until verified monetary provider costing is available; owner exemption is checked using protected roles.
- MovieStudio composites real video frames and native clip audio into export, retaining still animation only for scenes without a clip; all paid calls refresh member tokens at request time.
- Scheduled and database-triggered workers authenticate with the private scheduler token (service-only table, sent as x-internal-job-token) via requireInternalOrOwner, never the public anon key; memberships and wallet top-ups are fulfilled only by the signed Stripe webhook, and return pages just poll status.
- Oracle outfits are wallet-paid edits of the canonical portrait with cache/Library fallback off, so stale pictures never pose as new outfits; the dressed still replaces prerecorded loops and is the reference for reply clips. Chat (parseOutfitCommand) and the settings picker share one request path.
- Oracle's standby loop is a separate silent prerecorded clip chosen only after three minutes without activity while idle/listening; any interaction or chat state change exits it, and it never plays over a custom outfit.
- Oracle Videos (owner clips) live in oracle_clips with a private oracle-clips bucket; members read via is_active_member RLS and signed URLs, only the owner role writes, so clips stay members-only without a separate subscription system.
- Member templates copy a shared user_media row (allow_template) into the buyer's own folder through library-use-template; paid templates need a paid shop_purchases row and shared rules live in _shared/templateAccess.ts, so copies never depend on the creator's files or skip payment.
- Oracle's member-designed look is a wallet-paid edit of the canonical portrait built only from whitelisted choices (cleanLook); a new look clears the outfit, outfits edit the look, and a male look switches default voice and skips ad-voice fillers so voices never mismatch.
- Voice-level Oracle speech uses a procedural head sway (no mouth movement), keeping replies fast and free without implying lip-sync; real lip-sync stays in paid clips.
- Oracle mood awareness runs in the browser (oracleMood) for the current chat only and sends a short sanitized hint, never stored, so care stays free and non-surveillance.
- Oracle: fastest model for chat, stronger low-reasoning for deep questions, low-latency TTS; speed first.
- Shop sales credit creators' wallets via idempotent credit_creator_sale; cash payouts exclude wallet-credited sales, so nothing pays twice.
- New members get Oracle's free scripted welcome; apps soft-unlock via oracleDiscovery ([[UNLOCK:/path]]); safety pages stay open and "Show me everything" escapes.
- Signed-out / shows AppStorePage, installed launches PublicWelcomePage, signed-in / goes to Oracle; /download always shows AppStorePage so members can reach the website. Install CTAs use installRedirect to avoid dead hosts.
- App look = final theme layer in index.css; body avoids @apply (Tailwind copies rules naming applied classes onto body).
- Oracle human sounds are bundled clips chosen by a pure tested picker (oracleHumanSounds) in the speech queue; never paid, muted by mute, no cheeky sounds in serious moods.
