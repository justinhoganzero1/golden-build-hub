# src rules
- Library deletes remove only the member's own user_media rows (bulk delete filters by user_id) and never remove storage files, because the same file can still back Movie Maker projects, templates or other saved work.
- Phone layouts never scroll sideways: html/body clip horizontal overflow and option/tab rows wrap instead of using overflow-x scrolling; reserve horizontal scrollers for tables and picture carousels.
- Owner-only pages stay out of every user-facing route list (chat tool menu, tiles, headers) unless the signed-in account is admin; the routes themselves keep RequireAuth + RequireAdmin so hiding is never the only gate.
- Signed-out browser visitors to / (from Lovable or anywhere online) see the funny ad once per tab before the store page, with a skip button and an automatic hand-off to the site when it ends or fails; robots and the installed app skip it so search listings stay unchanged, and Lovable-mode end links open oraclelunar.com so visitors never stay on Lovable hosts.
- Google sign-ups (no birthday on the form) pass a one-time 16+ birthday step via RequireAuth → /age-required; a database trigger validates the age and blocks members from changing a saved birthday, so the client gate is never the only check.
- Library shares link to the public /watch player on oraclelunar.com (allowlisted own storage/asset sources only) instead of raw file links, and sent files are re-labelled with their real type, because files stored as generic octet-stream arrive blank on phones.
